Put your photos in this folder, then point to them from script.js.

Example:
  image: "images/first-meeting.jpg"

Tips:
- Portrait photos (roughly 4:5, like a polaroid) look the nicest in the
  frames, but any photo will work — it gets cropped to fit.
- Keep photos reasonably sized for the web (under ~1–2 MB each) so the
  site loads quickly. Most phone photos will need to be resized down.
- File names are case-sensitive on most web hosts — "Photo.JPG" and
  "photo.jpg" are treated as different files.
- If a path is wrong or a photo is missing, the site quietly falls back
  to the "Our photo goes here ♡" placeholder instead of breaking.
